## Remote audit

`tools/audit-static-origin.mjs` accepts an HTTPS origin and an exact generated
site directory. It rejects credential-bearing/non-origin URLs and symbolic
links, enumerates the generated tree, and verifies the remote deployment without
hard-coding an account subdomain.

The audit proved:

- all six deployable files return HTTP 200 and match generated bytes exactly;
- the index carries the generated no-script Content Security Policy and
  `X-Content-Type-Options: nosniff`;
- an unknown route returns status 404 with byte-identical generated `404.html`;
- `_headers` returns 404 rather than being exposed as content;
- `edgefossil-site.json` remains public-realm-only and has the expected semantic
  root.
